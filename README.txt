CAMPNEST WEB DESIGN ASSIGNMENT 2
================================

This project uses HTML and CSS only. No JavaScript file is included.

PAGES
-----
index.html             - Home page
accommodation.html     - Green View and New Hope Residence
accommodation-more.html- Unity Residence and Blue Dot
about.html             - About Us page
contact.html           - Contact Us page

STYLESHEET
----------
css/style.css          - Shared styles for all pages

HOW TO OPEN
-----------
1. Extract this ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser, or use Live Server.

NOTE
----
The contact form is a visual front-end example only. It does not send
messages because this version contains HTML and CSS only.
